- confirma workstream y branch;
- inspecciona el estado actual de la rama de integración;
- identifica archivos que necesitas tocar;
- identifica archivos compartidos;
- identifica dependencias y riesgos;
- no modifiques main;
- no despliegues producción;
- no cambies decisiones compartidas unilateralmente;
- mantén commits pequeños;
- añade tests para contratos nuevos;
- usa DEPENDENCY REQUEST cuando invadas ownership ajeno.
