# MLS-SND Source Registry

Estado: **estructura inicial**. Las fuentes concretas se incorporarán después de comprobar alcance y localizadores.

## 1. Objetivo

Registrar de manera auditable qué fuentes respaldan afirmaciones del tomo y para qué idioma, variedad, fenómeno y nivel analítico son apropiadas.

## 2. Criterios de admisión

Prioridad general:

1. instituciones lingüísticas y documentación normativa o descriptiva primaria;
2. gramáticas y manuales académicos de referencia;
3. artículos revisados por pares y monografías especializadas;
4. diccionarios de pronunciación u ortoépicos de autoridad;
5. recursos académicos o institucionales especializados;
6. materiales pedagógicos de calidad, solo como apoyo cuando corresponda.

La gratuidad es deseable, pero no reemplaza autoridad, pertinencia, metodología ni verificabilidad.

## 3. Registro mínimo por fuente

Cada fuente deberá registrar:

- `source_id`;
- referencia APA 7;
- autor/institución;
- título;
- año/versión;
- URL/DOI/identificador;
- acceso gratuito: sí/no/parcial;
- idioma;
- variedad cubierta;
- fenómenos cubiertos;
- tipo de fuente;
- nivel de autoridad;
- localizadores disponibles;
- limitaciones conocidas;
- fecha de verificación;
- estado editorial.

## 4. Regla de alcance

Una fuente sobre un idioma general no se tratará automáticamente como evidencia suficiente para una afirmación sobre una variedad concreta.

Una fuente normativa tampoco se tratará automáticamente como descripción exhaustiva del uso.

## 5. Localizadores

Según la fuente podrán utilizarse:

- página;
- sección;
- capítulo;
- tabla;
- figura;
- número de ejemplo;
- entrada lexicográfica;
- identificador persistente;
- otro localizador reproducible.

La URL sola no constituye por defecto un localizador suficiente para una afirmación material.

## 6. Conflictos

Cuando fuentes competentes discrepen:

1. registrar ambas;
2. comprobar variedad, población, fecha, método y nivel de análisis;
3. determinar si el desacuerdo es real o terminológico;
4. documentar la decisión editorial;
5. no fabricar consenso.

## 7. Relación con R33

El Source Registry facilita R33, pero una fuente registrada no valida automáticamente una entrada.

La validación requiere correspondencia entre **afirmación concreta ↔ evidencia concreta ↔ localizador concreto ↔ versión vigente del texto**.
