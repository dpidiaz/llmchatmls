# MLS-SND — Comparación transversal

Este directorio reúne entradas comparativas que conectan perfiles ya investigados sin borrar diferencias entre idiomas, variedades o niveles de análisis.

## Regla de dependencia

Las comparaciones sustantivas deben respetar los estados del `MLS-SND-MASTER-INVENTORY.md`. Un capítulo comparativo no convierte perfiles incompletos en evidencia y no debe generalizar fuera del alcance de las fuentes que sostienen cada afirmación.
