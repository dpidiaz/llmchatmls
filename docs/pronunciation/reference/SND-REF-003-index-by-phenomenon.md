## Cómo leer este índice

Este índice organiza **rutas de consulta**, no equivalencias lingüísticas.

Que dos entradas aparezcan bajo el mismo fenómeno significa únicamente que ambas tratan ese dominio. No implica que:

- tengan el mismo inventario;
- compartan el mismo análisis;
- los símbolos IPA sean equivalentes;
- una regla pueda transferirse de una lengua a otra.

Los enlaces editoriales deben resolverse por **ID canónico SND**, no por número de página o capítulo.
