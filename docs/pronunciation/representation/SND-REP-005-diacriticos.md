# SND-REP-005 — Diacríticos del IPA

**Estado:** LINGUISTIC_REVIEW.
**Dominio:** representación / fonética.
**Idioma:** transversal.

## 1. Qué son en este tomo

Los diacríticos son marcas que se añaden a un símbolo para indicar información fonética adicional.

MLS-SND los utilizará cuando el detalle representado sea relevante para la explicación y esté respaldado por la evidencia.

## 2. Principio de economía

Una transcripción más cargada de diacríticos no es automáticamente mejor.

Para una transcripción amplia, la recomendación editorial será usar la notación tipográficamente más simple que conserve la información crucial para el objetivo de la entrada.

## 3. Cuándo introducir un diacrítico

Un diacrítico deberá cumplir al menos una de estas condiciones:

- representar una diferencia central para el fenómeno;
- distinguir realizaciones que la entrada necesita comparar;
- reproducir con fidelidad una fuente especializada;
- aclarar un proceso que se perdería con una transcripción más amplia.

## 4. Cómo enseñarlos

No se pedirá al lector memorizar la lista completa.

Cada diacrítico aparecerá con:

- su forma;
- su nombre o función;
- un ejemplo pertinente;
- enlace al índice IPA;
- advertencia si otra tradición gráfica usa un signo parecido con función distinta.

## 5. Diacríticos y sistemas externos

Un acento agudo, grave u otra marca visible en una ortografía o romanización no se interpretará automáticamente como diacrítico IPA.

La función depende del sistema de representación.
