# SND-REP-008 — Transcripción amplia y transcripción estrecha

**Estado:** EVIDENCE_CHECKED.  
**Dominio:** transcripción fonética.  
**Idioma:** transversal.

## 1. El detalle es una decisión descriptiva

Una transcripción puede representar poca o mucha información fonética.

La diferencia entre **amplia** y **estrecha** describe el grado de detalle que se intenta registrar.

## 2. Transcripción amplia

Una transcripción amplia conserva la información necesaria para el objetivo descriptivo sin intentar capturar cada detalle fonético observable.

Para MLS-SND será el nivel predeterminado cuando el propósito sea explicar una categoría o contraste de manera clara.

## 3. Transcripción estrecha

Una transcripción estrecha incorpora más detalle fonético y puede resultar útil cuando una entrada trata variación fina, realizaciones específicas o procesos que una representación más amplia ocultaría.

## 4. No existe un punto único de corte

La evidencia introductoria describe un continuo: una transcripción puede ser muy amplia, muy estrecha o encontrarse entre ambos extremos.

Por eso MLS-SND no creará una regla mecánica del tipo “con diacríticos = estrecha; sin diacríticos = amplia”.

## 5. Propósito y audiencia

El nivel de detalle debe responder al propósito de la transcripción y a quién necesita interpretarla.

Esta idea coincide con la política MLS-SND de **mínima precisión suficiente**.
