# SND-REP-007 — Transcripción fonológica y transcripción fonética

**Estado:** EDITORIAL_REVIEW.  
**Dominio:** transcripción / fonología / fonética.  
**Idioma:** transversal.

## 1. Dos objetos distintos

MLS-SND distinguirá entre:

- **transcripción fonológica**, que representa unidades o análisis fonológicos;
- **transcripción fonética**, que representa realizaciones fonéticas.

La diferencia no es puramente tipográfica: corresponde a objetos analíticos distintos.

## 2. Barras /…/

Por convención, los fonemas suelen representarse entre barras.

Las barras indican que el símbolo se está utilizando como parte de un análisis fonológico, no que ese carácter tenga una única pronunciación física obligatoria.

## 3. Corchetes […]

Las realizaciones fonéticas se representan convencionalmente entre corchetes.

Un mismo fonema puede relacionarse con más de una realización fonética según el análisis y el contexto.

## 4. No confundir símbolo con nivel

El mismo carácter IPA puede aparecer entre barras y entre corchetes, pero el objeto representado cambia con la convención.

Por eso MLS-SND no interpretará /x/ y [x] como expresiones intercambiables.

## 5. Adaptación editorial

Cuando una fuente utilice otra convención o un análisis distinto, se conservará la lógica de la fuente y cualquier adaptación quedará documentada.
