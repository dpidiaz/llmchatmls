# SND-FND-013 — Tono

**Estado:** EVIDENCE_CHECKED.
**Dominio:** prosodia / fonología.
**Idioma:** transversal.

## 1. Qué significa “tono” aquí

MLS-SND reservará **tono** para patrones de altura tonal que cumplen una función lingüística documentada dentro de un sistema. Cuando haga falta describir el correlato acústico, se hablará de **frecuencia fundamental (F0)**; F0 es una medida física y *pitch/altura percibida* es una categoría perceptiva relacionada, no un sinónimo técnico exacto.

No utilizará “tono” como sinónimo general de entonación.

## 2. La altura de la voz no basta

Toda habla presenta variación melódica. Eso no significa que todas las lenguas organicen esa variación de la misma manera.

Cuando una lengua utilice contrastes tonales léxicos o gramaticales, el perfil correspondiente explicará:

- qué unidad porta el contraste;
- qué categorías reconoce la fuente;
- cómo se representan;
- qué variación se documenta;
- qué procesos contextuales afectan su realización.

## 3. Representación

MLS-SND podrá utilizar símbolos, números o convenciones locales para tono cuando una tradición o fuente los requiera, pero deberá identificar siempre el sistema.

Una notación tonal no se convertirá automáticamente a otra sin documentar la equivalencia analítica.

## 4. Tono no es acento tonal

El término **acento tonal** se reserva para perfiles donde esa categoría esté justificada por la tradición analítica y las fuentes.

No se enseñará mandarín y japonés como si fueran dos versiones del mismo sistema prosódico.
