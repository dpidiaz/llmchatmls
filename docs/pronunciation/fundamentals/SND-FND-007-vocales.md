# SND-FND-007 — Vocales: parámetros articulatorios

**Estado:** EVIDENCE_CHECKED.
**Dominio:** fonética articulatoria.
**Idioma:** transversal.

## 1. Idea central

Las vocales se describen mediante configuraciones del tracto vocal que forman un espacio continuo. Para una introducción funcional, MLS-SND utilizará como ejes básicos:

- altura;
- anterioridad/posterioridad;
- redondeamiento.

Otros rasgos —como nasalidad, duración o propiedades de raíz lingual— se introducirán solo donde sean relevantes para el idioma o análisis tratado.

## 2. Altura

La altura describe la posición vertical de la lengua durante la articulación vocálica.

Etiquetas como alta, media y baja sirven como categorías amplias. Un perfil puede requerir distinciones más finas.

## 3. Anterioridad/posterioridad

La posición horizontal de la lengua permite describir vocales anteriores, centrales y posteriores.

MLS-SND evitará tratar estas etiquetas como coordenadas anatómicas absolutamente discretas: representan regiones útiles dentro de un espacio articulatorio continuo.

## 4. Redondeamiento

La configuración de los labios puede distinguir vocales redondeadas y no redondeadas cuando ese rasgo sea pertinente.

## 5. Otros parámetros

La fuente de referencia también documenta nasalidad y longitud vocálica. MLS-SND los tratará en entradas independientes o dentro de perfiles cuando tengan función relevante.

## 9. Nota editorial

Los términos “alta/baja” y “anterior/posterior” describen categorías del modelo; no deben inducir al lector a imaginar posiciones discretas idénticas en todas las vocales o hablantes.
