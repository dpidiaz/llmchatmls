# SND-FND-004 — El aparato vocal y la articulación

**Estado:** EVIDENCE_CHECKED.
**Dominio:** fonética.
**Idioma:** transversal.
**Variedad:** no aplica.

## 1. Qué entendemos por articulación

En MLS-SND, **articulación** describe el uso coordinado de estructuras corporales para producir una señal lingüística hablada.

Para el habla, una parte central de esa producción ocurre en el tracto vocal mediante estructuras como labios, lengua, cavidades oral y nasal, faringe, laringe y pliegues vocales.

## 2. Para qué sirve conocer el aparato vocal

El objetivo no es memorizar anatomía por sí misma. La anatomía permite entender descripciones como:

- bilabial;
- alveolar;
- velar;
- glotal;
- oral;
- nasal;
- sonora/sorda cuando una fuente use esa distinción;
- altura y posición de la lengua para vocales.

## 3. Diagramas

MLS-SND podrá utilizar diagramas midsagitales para explicar posiciones articulatorias. Un diagrama representa una vista lateral del tracto vocal y debe acompañarse de etiquetas legibles.

La obra escrita debe seguir siendo comprensible aunque el lector no disponga de audio.

## 4. Límite editorial

Conocer la posición anatómica no basta para describir el sistema sonoro de una lengua. La relevancia lingüística de una articulación debe documentarse dentro del perfil correspondiente.
