# SND-FND-009 — Fonotáctica

**Estado:** LINGUISTIC_REVIEW.
**Dominio:** fonología.
**Idioma:** transversal.

## 1. Qué entendemos por fonotáctica

En MLS-SND, **fonotáctica** se refiere a los patrones y restricciones que condicionan qué secuencias o posiciones están permitidas o cómo se distribuyen dentro de una lengua o variedad. La frecuencia de una secuencia puede estudiarse además como gradiencia o probabilidad fonotáctica, pero no se confundirá automáticamente con una restricción categórica.

No se presentará como una lista universal de combinaciones permitidas.

## 2. Por qué es importante

Dos lenguas pueden disponer de sonidos comparables y, sin embargo, permitirlos en posiciones o combinaciones distintas.

Por eso aprender un inventario de consonantes y vocales no basta para comprender cómo se organizan las formas sonoras de una lengua.

## 3. Relación con la sílaba

La fonotáctica puede expresarse mediante restricciones sobre:

- ataques;
- núcleos;
- codas;
- secuencias de segmentos;
- posiciones dentro de palabra u otras unidades.

Cada perfil deberá describir únicamente las restricciones necesarias para explicar los fenómenos tratados.

## 4. Evitar falsas reglas desde la ortografía

Una secuencia de letras no es evidencia suficiente de que exista la misma secuencia fonética.

Las restricciones fonotácticas se documentarán con análisis lingüístico o datos de la lengua, no mediante inspección de la escritura.
