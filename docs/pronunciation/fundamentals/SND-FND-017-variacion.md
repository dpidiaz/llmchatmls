# SND-FND-017 — Variación: región, sociedad, estilo y tiempo

**Estado:** READY_FOR_COMPOSITION.  
**Dominio:** variación / sociolingüística.  
**Idioma:** transversal.

## 1. La variación no es una excepción

MLS-SND parte de que una lengua no tiene necesariamente una única realización fonética uniforme.

La variación puede aparecer en todos los dominios del lenguaje, incluido el fonético, y puede correlacionarse con factores como:

- lugar;
- grupo social;
- estilo/contexto;
- edad o cambio histórico;
- redes e identidades.

## 2. Variedad no significa desviación

Una variedad regional o social no se presentará automáticamente como versión “incorrecta” de una supuesta forma neutra.

Cuando una fuente utilice una norma o estándar, MLS-SND diferenciará:

- descripción de uso;
- codificación normativa;
- prestigio social;
- decisión editorial de referencia.

## 3. Variación regional

Las diferencias de lugar pueden asociarse con variedades regionales dentro de un mismo idioma.

Por ello, etiquetas amplias como “inglés estadounidense”, “francés” o “español de Guatemala” requieren delimitación adicional cuando una afirmación fonética dependa de región.

## 4. Variación estilística

El comportamiento lingüístico puede cambiar según el contexto de interacción.

Cuando una realización dependa de formalidad, estilo o situación, la entrada deberá indicar ese alcance en lugar de presentarla como propiedad estable de todos los contextos.

## 5. Cambio

Las lenguas cambian con el tiempo.

Una fuente antigua puede seguir siendo valiosa, pero una afirmación sobre pronunciación contemporánea no debe heredarse sin control de fecha cuando exista evidencia de cambio relevante.
