# SND-FND-001 — El sonido como parte del idioma

**Estado:** EDITORIAL_REVIEW — PASS.  
**Dominio:** fundamentos / orientación.  
**Idioma:** transversal.

## 1. Una lengua también tiene una dimensión física

Las lenguas habladas se realizan mediante señales físicas que pueden producirse, transmitirse, percibirse y describirse. La fonética ofrece herramientas para estudiar esa dimensión sin reducirla a la ortografía.

En MLS-SND, esto justifica tratar la pronunciación como objeto propio de consulta junto con gramática y escritura.

## 2. El tomo no convierte “sonido” en una categoría única

En lenguaje cotidiano podemos decir “sonido” de manera amplia. En las entradas técnicas, MLS-SND distinguirá cuando sea necesario:

- señal física;
- phone o realización fonética;
- fonema/unidad fonológica;
- rasgo prosódico;
- símbolo de transcripción.

Esta precisión evita hablar de letras, fonemas y realizaciones como si fueran el mismo objeto.

## 3. Producción, percepción y organización

El tomo estudia tres preguntas diferentes pero relacionadas:

1. **cómo se produce y se manifiesta físicamente una señal hablada**;
2. **cómo puede percibirse y categorizarse**;
3. **cómo una lengua organiza contrastes y patrones sonoros**.

Las entradas de fonética, percepción y fonología desarrollan cada una de estas dimensiones por separado.

## 4. Regla editorial

MLS-SND no afirmará que dominar pronunciación equivale a dominar una lengua ni que existe una única pronunciación correcta para cada idioma. Su función es dar herramientas para comprender sistemas sonoros documentados y sus variedades.
