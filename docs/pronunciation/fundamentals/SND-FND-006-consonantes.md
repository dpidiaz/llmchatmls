# SND-FND-006 — Consonantes: parámetros articulatorios

**Estado:** EVIDENCE_CHECKED.
**Dominio:** fonética articulatoria.
**Idioma:** transversal.

## 1. Idea central

Las consonantes pueden describirse mediante propiedades articulatorias. Para la introducción de MLS-SND se utilizarán tres ejes especialmente útiles:

1. **fonación/sonoridad** cuando la distinción pertinente sea presencia o ausencia de vibración de los pliegues vocales;
2. **lugar de articulación**;
3. **modo de articulación**.

Este esquema sirve para organizar muchas consonantes comunes, pero no debe presentarse como descripción exhaustiva de todas las posibilidades fonéticas.

## 2. Lugar de articulación

El lugar describe dónde se forma una constricción, normalmente mediante la relación entre un articulador activo y uno pasivo.

El tomo introducirá únicamente los lugares que aparezcan en los perfiles estudiados y remitirá al índice IPA para el panorama más amplio.

## 3. Fonación y sonoridad

La vibración de los pliegues vocales se denomina habitualmente **voicing**; MLS-SND usará “sonoro/sonora” y “sordo/sorda” cuando corresponda a la terminología española del fenómeno descrito.

No se utilizará “sonoridad” de manera ambigua para referirse a loudness/intensidad.

## 4. Modo de articulación

El modo describe cómo circula el aire a través del tracto vocal según el tipo y grado de constricción.

Categorías concretas como oclusiva, fricativa, nasal o aproximante se introducirán cuando sean necesarias para leer el IPA o un perfil lingüístico.
