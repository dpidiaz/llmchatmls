# SND-JA-003 — Vocales y duración

**Estado:** RESEARCHED.  
**Idioma:** japonés.  
**Dominio:** fonética / duración.

## 1. Alcance de esta wave

Esta entrada no congela todavía un inventario fonético completo de las vocales japonesas.

Su objetivo es documentar una distinción que el CSJ representa explícitamente: vocales simples frente a elementos de vocal larga dentro de su esquema segmental.

## 2. Etiquetas del CSJ

El manual segmental enumera etiquetas para:

- a, i, u, e, o;
- aH, iH, uH, eH, oH como vocales largas dentro del sistema de etiquetado.

El propio manual explica que `H` representa el **segundo elemento de una vocal larga**.

También dispone de etiquetas específicas para vocales ensordecidas dentro de la anotación del corpus.

## 3. Consecuencia para MLS-SND

La duración debe describirse como dimensión sonora y estructural, no deducirse solo de kana u ortografía.

El perfil japonés deberá explicar posteriormente:

- qué contrastes de longitud son fonológicamente relevantes;
- cómo se realizan acústicamente;
- cómo se relacionan con mora y escritura;
- qué variación contextual aparece.
