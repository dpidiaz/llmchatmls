# SND-ESGT-001 — Alcance y variedades del español de Guatemala

**Estado:** EVIDENCE_CHECKED.
**Idioma:** español.
**Área:** Guatemala.
**Dominio:** alcance dialectal / política descriptiva.
**Referencia editorial:** REFERENCE_PROVISIONAL.

## 1. Qué describe este perfil

MLS-SND tratará **español de Guatemala** como un perfil nacional con variación interna explícita.

Por ahora, el tomo **no** escogerá “Ciudad de Guatemala” como sustituto de toda la variedad nacional ni presentará una única pronunciación guatemalteca como homogénea.

## 2. Qué muestran las fuentes nacionales

Herrera y Montenegro describen la variante guatemalteca como relativamente poco variable en términos fonéticos a escala diatópica, generacional y de sexo, pero señalan rasgos que permiten distinguir tres áreas mayores: centro-occidental, oriental y norteña, además de fenómenos asociados a grupos etarios.

La misma fuente declara que su panorama no es una descripción fonético-fonológica exhaustiva.

Utgård, mediante una red de 22 localidades y 88 informantes, también encuentra poca variación global, pero sus conclusiones proponen isoglosas y zonas solo de manera tentativa.

## 3. Las zonificaciones no se fusionan mecánicamente

Las categorías regionales de Herrera/Montenegro y las zonas tentativas derivadas del atlas de Utgård no son idénticas.

Por tanto MLS-SND no creará una zonificación “definitiva” combinándolas.

La política será:

- conservar el sistema regional de cada fuente;
- etiquetar la localidad o área concreta cuando un claim dependa de ella;
- usar etiquetas nacionales solo para rasgos que la evidencia permita generalizar;
- registrar como OPEN_QUESTION cualquier incompatibilidad de zonificación.

## 4. Contacto lingüístico

Guatemala es multilingüe y existe una literatura específica sobre español en contacto con lenguas mayas.

El atlas segmental de Utgård se diseñó principalmente con informantes monolingües y deja el contacto para otros estudios, con excepciones como Livingston.

Por ello MLS-SND distinguirá, cuando la fuente lo requiera:

- español monolingüe;
- español bilingüe/L2;
- comunidades de contacto específicas;
- variedad regional.

No se atribuirá automáticamente al “español guatemalteco general” un rasgo documentado solo en una comunidad bilingüe concreta.

## 5. Decisión editorial de esta wave

**REFERENCE_PROVISIONAL se mantiene.**

La referencia operativa para el tomo será inicialmente:

> perfil nacional de Guatemala + etiquetas regionales/sociales/generacionales/contacto cuando sean materiales.

Ciudad de Guatemala podrá convertirse después en una **subreferencia urbana** si se reúne evidencia suficiente; no se fija todavía como referencia única.
