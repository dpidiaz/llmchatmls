# MLS-SND pt-BR-rio — Checklist para LINGUISTIC_REVIEW

Esta lista está diseñada para un revisor distinto del autor de Wave 01.

## A. Alcance

- [ ] Confirmar que PB_BROAD, RIO_CARIOCA, RIO_SUBSCOPE y FLUMINENSE se usan de forma consistente.
- [ ] Verificar que ninguna cifra NURC se presenta como representativa del Río de 2026.
- [ ] Comprobar que Copacabana >56 y FavRio permanecen como submuestras explícitas.
- [ ] Revisar si “fala culta” requiere una etiqueta más precisa en el lector final.

## B. Transcripción y análisis

- [ ] Revisar uso de /S/, /R/ y /L/ como notación de análisis/archifonema cuando aparezca; no asumir que todas las fuentes usan el mismo marco.
- [ ] Verificar toda forma IPA antes de composición.
- [ ] Separar fonema/análisis de realización fonética.
- [ ] Revisar tratamiento de nasalidad contrastiva vs. contextual.

## C. Fuentes

- [ ] Auditar directamente Callou (2009), pp. 129–152, contra PTBR-001/005/006/007/008.
- [ ] Auditar Callou, Moraes & Leite (1998) contra PTBR-007.
- [ ] Obtener texto completo de Silva (2026) antes de incorporar resultados, no solo alcance.
- [ ] Obtener texto completo de Orsini (1995) antes de congelar inventario vocálico.
- [ ] Auditar integralmente Moraes & Wetzels (1992) antes de expandir PTBR-003.
- [ ] Resolver discrepancia de Machado et al. (2010): 1344 vs. 1152.
- [ ] Auditar capítulo completo de Frota & Moraes (2016) antes de publicar contornos específicos.
- [ ] Localizar fuente carioca explícita para acento/ritmo; Moraes (2003) queda PB_BROAD.

## D. Cobertura

- [ ] PTBR-002: convertir mapa en inventario solo con evidencia directa suficiente.
- [ ] PTBR-003: ampliar nasalización contextual.
- [ ] PTBR-005: cubrir consonantes fuera de las codas ya trabajadas.
- [ ] PTBR-009: localizar muestra explícitamente carioca.
- [ ] PTBR-010: validar contornos y tipos de enunciado.

## E. Gate

Una entrada solo pasa a LINGUISTIC_REVIEW aprobado cuando:

1. su análisis es coherente con la(s) fuente(s);
2. la variedad está correctamente delimitada;
3. los símbolos/transcripciones están comprobados;
4. no se ocultan análisis alternativos materiales;
5. las limitaciones de muestra/fecha siguen visibles;
6. no hay claim marcado VERIFIED cuyo localizador no sostenga exactamente el texto.
