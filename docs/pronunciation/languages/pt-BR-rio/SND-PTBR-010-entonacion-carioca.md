# SND-PTBR-010 — Entonación carioca: marco descriptivo inicial

**Estado:** EVIDENCE_CHECKED para **alcance y funciones**; contornos específicos todavía OPEN_QUESTION.  
**Idioma:** portugués brasileño.  
**Variedad:** Río de Janeiro.  
**Dominio:** prosodia / entonación.

## 1. Base de referencia

Frota y Moraes (2016) describen la entonación del portugués comparando una variedad de Lisboa para portugués europeo con una variedad de **Río de Janeiro** para portugués brasileño.

Esto da a MLS-SND una fuente explícitamente delimitada para construir el capítulo carioca de entonación.

## 2. Qué dimensiones cubre la fuente

El capítulo organiza la descripción en torno a funciones como:

- demarcación;
- realce/prominencia;
- distinción de tipos de enunciado.

También considera:

- agrupamiento entonacional;
- tamaño de frases entonativas;
- distribución de eventos tonales;
- realización de fronteras;
- preguntas wh y preguntas sí/no.

## 3. Regla editorial

MLS-SND no resumirá la “entonación carioca” con una metáfora como “melodiosa” o “cantada”.

El perfil deberá describir:

1. función;
2. dominio prosódico;
3. contorno o eventos tonales documentados;
4. tipo de enunciado;
5. muestra/variedad.

## 4. Actos de habla y percepción

Moraes y Rilliard (2018) muestran, para portugués brasileño en su corpus experimental, que oyentes pueden discriminar actos de habla usando pistas prosódicas y que el contorno de F0, junto con su anclaje segmental, forma parte central de esa descripción.

Esta fuente se utiliza aquí como apoyo metodológico, no para afirmar que un contorno específico representa automáticamente a todo Río.

## 5. Qué queda abierto

Todavía no se promueve a VERIFIED ningún claim sobre:

- patrón exacto de declarativas cariocas;
- patrón exacto de interrogativas totales;
- patrón de wh-questions;
- rango tonal;
- diferencias por género, edad o estilo.

Esos puntos requieren auditoría del texto completo y, cuando sea posible, datos contemporáneos adicionales.
