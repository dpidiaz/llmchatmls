# SND-PTBR-001 — Portugués brasileño amplio vs. habla carioca

**Estado:** DRAFTED.
**Idioma:** portugués.
**Variedad:** Brasil / Río de Janeiro.
**Dominio:** alcance descriptivo / variación.

## 1. Decisión de alcance

MLS-SND distinguirá de forma explícita entre:

- **PB_BROAD** — afirmaciones respaldadas para portugués brasileño con alcance mayor;
- **RIO_CARIOCA** — afirmaciones respaldadas específicamente para el habla de Río de Janeiro;
- otras variedades brasileñas identificadas por su nombre.

La referencia carioca del proyecto no se utilizará como sustituto de todo el portugués brasileño.

## 2. Base documental inicial

Dinah Callou dedica un capítulo completo a *Um perfil da fala carioca*, publicado en *Dos sons às palavras: nas trilas da Língua Portuguesa*.

La existencia de una descripción específica para el habla carioca justifica tratarla como objeto delimitado dentro del perfil brasileño y no convertir automáticamente sus rasgos en reglas nacionales.

## 3. Qué falta antes de fijar el perfil

La entrada de alcance no cerrará todavía afirmaciones sobre:

- vocalismo;
- nasalidad;
- /s/ en coda;
- róticas;
- /l/ en coda;
- reducción;
- acento;
- ritmo;
- entonación.

Cada uno de esos fenómenos necesita claims y localizadores propios.

## 4. Decisión editorial

El estado permanece como **REFERENCE_PROVISIONAL**.

La futura referencia principal será habla urbana de Río de Janeiro cuando exista evidencia suficiente para el fenómeno tratado. Los datos de otras ciudades brasileñas se etiquetarán por separado.
