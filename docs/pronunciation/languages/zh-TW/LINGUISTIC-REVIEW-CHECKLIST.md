# zh-TW — Checklist para revisión lingüística independiente

La persona/chat revisor no debe asumir que EVIDENCE_CHECKED equivale a aprobación lingüística.

## A. Alcance

- [ ] ¿Taiwan Mandarin está delimitado sin presentarlo como homogéneo?
- [ ] ¿Norte/centro/Taipei se mantienen separados cuando la fuente lo exige?
- [ ] ¿Los estudios con muestras pequeñas conservan sus límites?

## B. Segmentos

- [ ] ¿SND-ZHTW-003 separa inventario canónico de realizaciones taiwanesas?
- [ ] ¿Las sibilantes [s ʂ ɕ] se presentan como categorías del análisis/fuente, no como realizaciones obligatorias?
- [ ] ¿Los mergers se describen como variables y contextuales?
- [ ] ¿Los datos de Zhang (2009) no se generalizan fuera de seis hombres de Taipei?

## C. Sílaba

- [ ] ¿La organización onset/rhyme de Zhuyin no se confunde con una teoría fonológica universal?
- [ ] ¿Las codas nasales se presentan con su evidencia de variación?
- [ ] ¿Se evita deducir pronunciación solo desde la tabla Zhuyin?

## D. Romanización

- [ ] ¿Hanyu Pinyin se presenta como capa auxiliar de consulta y no como IPA?
- [ ] ¿La evidencia del diccionario MOE basta para la decisión editorial propuesta?
- [ ] ¿Hace falta documentar sistemas históricos/alternativos de Taiwán antes de fijar política final?

## E. Prosodia

- [ ] ¿Las versiones de ZHTW-004/005 de la rama tonal paralela son superiores o complementarias?
- [ ] ¿Tone 3 sandhi sigue bloqueado hasta reconciliar evidencia?
- [ ] ¿Se distinguen contornos fonéticos y representaciones fonológicas?

## F. R33

- [ ] ¿Cada claim usa un localizador verificable?
- [ ] ¿Las fuentes locales deben recibir IDs globales?
- [ ] ¿Hay afirmaciones que exceden abstracts o registros institucionales?
- [ ] ¿Se requiere lectura del texto completo antes de promoción?

## Salida esperada

El revisor debe devolver por entrada:
- PASS;
- PASS_WITH_SCOPE_WARNING;
- CHANGES_REQUIRED;
- BLOCKED_BY_EVIDENCE;

y justificar cualquier cambio de estado.
