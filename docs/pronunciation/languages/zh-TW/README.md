## Alcance candidato

Segmentos; sílaba; tonos; variación tonal; Zhuyin; romanización; escritura.

## Principios fijados en esta wave

1. Taiwan Mandarin no se trata como una realización fonética homogénea.
2. Zhuyin, Hanyu Pinyin, IPA y caracteres son capas con funciones distintas.
3. La descripción de Tone 1 debe conservar la variación norte/centro documentada.
4. Las representaciones fonológicas propuestas por autores se etiquetan como ANALYTICAL_CHOICE.
5. Tone 3 sandhi queda bloqueado cuando las fuentes no convergen.

## Gap principal después de wave 01

Aún falta una descripción fonética integral contemporánea de Taiwan Mandarin para:
- inventario segmental;
- estructura silábica;
- realizaciones de Tone 2–4;
- procesos tonales distintos de los ya investigados;
- variación por contacto más allá de los casos resumidos por Fon & Chuang.

## Dependencias para la siguiente wave

1. completar el inventario segmental con localizadores de capítulo y análisis alternativos;
2. resolver Tone 3 sandhi con lectura metodológica comparada;
3. decidir si Hanyu Pinyin se adopta globalmente como capa latina auxiliar;
4. promover, si el coordinador lo aprueba, las fuentes locales al Source Registry global;
5. someter las entradas EVIDENCE_CHECKED a LINGUISTIC_REVIEW independiente.

## Regla

Ninguna lista de fenómenos constituye por sí sola una afirmación fonética validada. Toda ampliación debe conservar la distinción entre convención institucional, descripción fonética, análisis fonológico, variación y decisión editorial.
