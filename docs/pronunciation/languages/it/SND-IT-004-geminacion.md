# SND-IT-004 — Geminación y duración consonántica

**Estado:** EDITORIAL_REVIEW  
**Idioma:** italiano.  
**Dominio:** fonética / fonología.  
**Dependencia:** SND-SRC-0028 canonicalizada; LINGUISTIC_REVIEW PASS.

## 1. Qué fenómeno se investiga

La literatura experimental sobre italiano distingue consonantes simples y geminadas y trata la geminación léxica como contrastiva.

Para MLS-SND esto significa que la duración consonántica no puede reducirse a “letras dobles”: debe describirse como fenómeno sonoro y, después, relacionarse con la escritura cuando corresponda.

## 2. Evidencia experimental candidata

La base GEMMA contiene pares de materiales VCV y VCCV para consonantes no geminadas y geminadas y registra duraciones de vocales y consonantes en casos donde existe el contraste singleton/geminate.

El conjunto fue producido por seis hablantes adultos de italiano estándar criados y residentes en Roma.

## 3. Contraste léxico

La fuente describe la geminación léxica italiana como relevante para distinguir palabras y organiza los datos explícitamente alrededor de consonantes simples frente a geminadas.

## 4. Qué no se cierra todavía

Esta entrada no decide aún:

- el análisis fonológico exacto de todas las geminadas;
- el inventario completo de consonantes que contrastan por longitud;
- la relación entre geminación léxica y raddoppiamento sintattico;
- la extensión regional del patrón;
- la política definitiva de transcripción /Cː/ frente a otros análisis.
