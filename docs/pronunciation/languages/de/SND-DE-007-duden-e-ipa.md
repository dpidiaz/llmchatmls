# SND-DE-007 — Duden e IPA

**Estado:** EDITORIAL_REVIEW  
**Idioma:** alemán.  
**Dominio:** pronunciación / transcripción / lexicografía.

## 1. Función de Duden en MLS-SND

Duden será una fuente lexicográfica de referencia para pronunciaciones concretas y para comprobar cómo una tradición de consulta alemana representa pronunciación mediante IPA.

No se utilizará como prueba de que todos los hablantes de alemán de Alemania, Austria y Suiza realizan una palabra de la misma manera.

## 2. Uso de IPA

La página de ayuda de Duden declara que, para palabras o partes de palabra cuya pronunciación puede presentar dificultad, las indicaciones se muestran en transcripción fonética utilizando el sistema de la International Phonetic Association.

Duden publica además una tabla de los signos y combinaciones de signos que utiliza.

## 3. Longitud y acento

En entradas sin transcripción propia, Duden utiliza marcas gráficas bajo la palabra para indicar vocal breve o larga en posición acentuada.

La página también explica signos para longitud, nasalización, acento y consonantes silábicas.

## 4. Límite editorial

MLS-SND separará:

- **pronunciación lexicográfica Duden**;
- **descripción fonética de una variedad**;
- **variación nacional/regional real**.

Una entrada de diccionario no sustituye por sí sola una investigación sobre el estándar austríaco o suizo.
