# SND-DE-004 — Consonantes: sistema y límites del análisis

**Estado:** EVIDENCE_CHECKED.  
**Idioma:** alemán.  
**Dominio:** consonantes / fonología / fonética.  
**Alcance:** variedad ilustrada por Kohler (1990).

## 1. Tabla consonántica y análisis

Kohler presenta una tabla de consonantes organizada por lugar y modo de articulación. La tabla lista fonemas, con excepciones explícitas para [ç], [x] y [ʔ], cuya distribución se trata aparte.

MLS-SND conservará esa distinción entre **inventario fonémico adoptado** y **segmentos que aparecen en la transcripción fonética**.

## 2. [ç] y [x]: contexto y morfología

El artículo propone tratar [ç] y [x] como alófonos de /x/ cuando se dispone de información sobre posición y estructura morfológica.

También muestra que, sin esa información morfémica, una transcripción IPA debe distinguir los segmentos para representar la realización observada.

Este caso es especialmente útil para mostrar por qué una transcripción fonética y un análisis fonológico no son el mismo objeto.

## 3. [ʔ] y estructura morfológica

Kohler discute igualmente el golpe glotal como segmento cuya aparición puede inferirse a partir de estructura morfémica en ciertos casos; cuando esa información no está disponible, necesita representarse en la transcripción.

## 4. /r/ y variación contextual

La fuente describe una realización de /r/ que varía según contexto: puede aproximantizarse intervocálicamente, ensordecerse tras obstruyentes sordas y vocalizarse postvocálicamente antes de consonante o al final de palabra.

Estas realizaciones se desarrollan en SND-DE-006.

## 7. Nota editorial

El tratamiento de [ç]/[x] se presenta como análisis de Kohler, no como declaración de que todas las teorías fonológicas del alemán deban adoptar exactamente la misma representación subyacente.
