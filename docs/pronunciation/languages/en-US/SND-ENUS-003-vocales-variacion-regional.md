# SND-ENUS-003 — Sistemas vocálicos y variación regional

**Estado:** RESEARCHED.
**Idioma:** inglés.
**Variedad:** Estados Unidos; arquitectura multirreferencia.
**Dominio:** vocales / variación regional.

## 1. Decisión editorial

MLS-SND no publicará una única tabla vocálica bajo la etiqueta “inglés estadounidense” sin indicar de qué variedad o nivel de abstracción procede.

La investigación de esta wave muestra que la variación vocálica regional es suficientemente estructural como para requerir una entrada propia y referencias regionales explícitas.

## 2. Base documental inicial

### Southern Michigan

SND-SRC-0005 documenta un perfil regional del sur de Michigan dentro del área Northern Cities y vincula esa región con cambios vocálicos.

### Atlas of North American English

La fuente candidata ENUS-CAND-001 está diseñada específicamente para describir pronunciación, sistemas vocálicos, cambios sonoros y regiones dialectales de Norteamérica.

La descripción editorial de De Gruyter informa que el Atlas:
- se basa en una encuesta de 762 hablantes locales de áreas urbanizadas de Norteamérica;
- contiene 139 mapas;
- contiene 120 diagramas vocálicos de hablantes;
- utiliza cambios sonoros para redefinir fronteras dialectales.

Estos datos justifican utilizar el Atlas como fuente de **arquitectura regional**, pero todavía no bastan para copiar o reconstruir tablas de vocales concretas sin consultar los capítulos y mapas correspondientes.

## 3. Cómo se representará en MLS-SND

El perfil en-US distinguirá tres niveles:

### A. Contrastes de alcance amplio

Solo se incluirán como “ampliamente distribuidos” cuando varias fuentes permitan sostener el alcance.

### B. Perfiles regionales

Ejemplos como Southern Michigan tendrán sus propias tablas/transcripciones si la fuente las respalda.

### C. Cambios y variantes

Los cambios vocálicos se presentarán con región, generación/fecha y fuente cuando esos factores sean materiales.

## 4. Regla de transcripción

Una realización regional no sustituirá automáticamente el símbolo fonológico usado para organizar una comparación nacional.

MLS-SND distinguirá:
- categoría analítica;
- realización fonética;
- variedad;
- contexto;
- fecha de los datos.

## 7. Nota editorial

Esta entrada es deliberadamente una **arquitectura de variación**, no una lista de vocales. La tabla fonética vendrá después de decidir qué nivel —fonémico transversal o realización regional— se está mostrando.
