# 🇰🇷 Korean profile — Source map

**Wave:** 01  
**Scope:** Seoul Korean / institutional Standard Korean, kept distinct.  
**Rule:** local source IDs are temporary to avoid collisions with parallel MLS-SND branches. The integrator may promote them to canonical SND-SRC IDs.

## Existing canonical sources

### SND-SRC-0012 — National Institute of Korean Language: Romanization of Korean
- Scope: institutional Romanization Revised; explicitly based on standard Korean pronunciation.
- Locator: “1. Basic Principles for Transcription”; “2. Summary of the Transcription System”.
- Use: KO-009, KO-010; limited support for KO-001.
- Warning: romanization is not a complete phonetic transcription.

### SND-SRC-0020 — Lee (1993), Korean, JIPA
- Scope: Illustration of the IPA.
- Locator: pp. 28–31.
- Use: historical/reference map for segmental description.
- Warning: not used as the sole description of present-day Seoul Korean.

### SND-SRC-0021 — Schweizer, Ahn & Kwon (2026)
- Scope: Seoul Korean stops, phrase-initial and word-medial.
- Locator: abstract; sections on production experiment, corpus, discussion; JIPA 56, e6.
- Use: KO-003.
- Strength: contemporary, peer-reviewed, position-sensitive phonetics.

## Editorial boundary

No source in this map authorizes treating:
- “standard Korean” = every realization of Seoul Korean;
- 1993 IPA values = unchanged present-day values;
- NIKL pronunciation rules = frequency claims about spontaneous speech;
- Romanization Revised = phonetic transcription.
