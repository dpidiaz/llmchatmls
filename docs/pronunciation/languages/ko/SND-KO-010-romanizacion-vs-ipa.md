# SND-KO-010 — Romanización Revisada e IPA cumplen funciones distintas

**Estado:** LINGUISTIC_REVIEW.
**Idioma:** coreano  
**Dominio:** romanización / transcripción

## 1. Romanización Revisada

El NIKL define la Romanización Revisada como un sistema basado en la pronunciación estándar y orientado a representar coreano mediante letras romanas.

La misma normativa deja explícitamente fuera algunos detalles: por ejemplo, no representa la longitud vocálica.

## 2. IPA

El IPA es la capa descriptiva fonética compartida por MLS-SND.

Por ello:
- una forma romanizada no se leerá como una cadena IPA;
- símbolos iguales visualmente pueden tener funciones distintas según el sistema;
- cuando el objetivo sea describir realización fonética, MLS-SND añadirá IPA en lugar de sobrecargar la romanización.

## 3. Relación con KO-009

KO-009 documenta la Romanización Revisada como sistema.

Esta entrada documenta **la frontera editorial entre romanización y transcripción fonética** para evitar equivalencias falsas.
