# 2. Cómo usar este tomo

No necesitas memorizar el AFI ni estudiar todos los capítulos en orden antes de consultar una pronunciación.

Este libro está construido como una red de entradas.

## Si empiezas desde cero

Una ruta recomendable es:

1. **Fonética y fonología** — entender qué describe cada una.
2. **Articulación** — ubicar las partes del tracto vocal necesarias para las explicaciones.
3. **Consonantes y vocales** — aprender las dimensiones básicas con las que se describen.
4. **Sílaba y fonotáctica** — entender por qué los sonidos no se combinan igual en todas las lenguas.
5. **Prosodia** — duración, acento, ritmo, tono y entonación.
6. **AFI/IPA y transcripción** — aprender a leer los símbolos que realmente aparecen en el tomo.
7. **Perfil del idioma** — aplicar las herramientas al sistema que te interesa.

No es obligatorio completar una parte para consultar la siguiente.

## Si buscas un sonido o fenómeno concreto

Puedes comenzar por:

- el índice del idioma;
- el índice por fenómeno;
- el índice IPA;
- el glosario.

Cada entrada debe llevarte a las definiciones previas que necesita.

## Cómo leer una transcripción

Este tomo distingue varios tipos de representación.

### /…/

Cuando corresponde, las barras indican una representación fonológica.

### […]

Cuando corresponde, los corchetes indican una representación fonética.

### Escritura normal

La ortografía de una lengua se presenta como escritura, no como transcripción fonética.

### Romanización o transliteración

Si una entrada utiliza una romanización o transliteración, el sistema debe identificarse.

No debes asumir que una forma escrita en alfabeto latino es IPA.

## No intentes convertir cada símbolo en una letra conocida

Una de las funciones del AFI es precisamente permitir que la descripción no dependa de una ortografía concreta.

Por eso la pregunta más útil suele ser:

> ¿Qué propiedad representa este símbolo aquí?

y no:

> ¿Qué letra española es?

## Cómo leer las comparaciones

Las comparaciones del MLS utilizan cuatro etiquetas editoriales:

### IDENTIDAD DOCUMENTADA

Se usa de forma excepcional cuando la evidencia permite tratar dos realizaciones como equivalentes para el nivel de detalle de la entrada.

### SEMEJANZA PARCIAL

Hay propiedades compartidas, pero también diferencias que importan.

### APROXIMACIÓN ARTICULATORIA

La comparación ayuda a encontrar una posición o movimiento inicial, pero no describe un sonido idéntico.

### SIN EQUIVALENTE DIRECTO ÚTIL

Buscar un sonido conocido produciría más confusión que ayuda.

En ese caso, la entrada explica el fenómeno desde sus propias propiedades.

## Qué hacer cuando dos fuentes no coinciden

No toda diferencia entre fuentes significa que una esté equivocada.

Pueden estar describiendo:

- variedades diferentes;
- épocas distintas;
- registros distintos;
- hablantes diferentes;
- niveles de transcripción diferentes;
- análisis fonológicos alternativos.

Cuando el desacuerdo afecte la explicación, el tomo debe indicarlo.

## Norma y uso no son lo mismo

Una entrada puede incluir una pronunciación recomendada por un diccionario o institución.

Eso no significa automáticamente que todos los hablantes la utilicen.

Busca etiquetas como:

- norma;
- variante documentada;
- variedad de referencia;
- corpus;
- muestra;
- decisión editorial MLS.

## Puedes saltar entre idiomas

Las entradas transversales están diseñadas para evitar repetir la misma definición diez veces.

Por ejemplo, la explicación general de **nasalización** puede aparecer una sola vez y después enlazarse desde varios perfiles.

El hecho de compartir una entrada general no significa que el fenómeno funcione de manera idéntica en todas las lenguas.
