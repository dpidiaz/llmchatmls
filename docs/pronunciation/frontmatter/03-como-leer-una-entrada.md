# 3. Cómo leer una entrada

Cada entrada comienza en una página nueva para que puedas reconocer con facilidad dónde inicia un concepto.

Una entrada puede ocupar más de una página.

## Encabezado

El encabezado puede incluir:

- título;
- ID estable;
- idioma;
- bandera;
- variedad;
- dominio;
- nivel de representación.

No todos esos campos aparecen necesariamente en cada entrada.

## ID estable

Los códigos como:

`SND-JA-010`

identifican una entrada aunque cambie de capítulo o página en una futura edición.

No necesitas memorizar estos IDs; sirven para mantener enlaces y referencias estables.

## Idioma y variedad

Una etiqueta como:

> **Idioma:** japonés  
> **Variedad:** Tokio / lengua común para el ancla prosódica

te dice qué alcance tiene la explicación.

Si una afirmación solo corresponde a una muestra o región concreta, la entrada debe indicarlo.

## Dominio

Una entrada puede pertenecer a uno o varios dominios:

- fonética;
- fonología;
- pronunciación;
- prosodia;
- escritura;
- transcripción;
- variación.

Esto ayuda a distinguir, por ejemplo, una regla de romanización de una descripción fonética.

## Explicación principal

La primera parte responde:

> ¿Qué es este fenómeno y por qué importa aquí?

Las secciones posteriores pueden ampliar:

- producción;
- percepción;
- contraste;
- contexto;
- escritura;
- variación;
- comparación.

## Escritura, romanización e IPA

Cuando una lengua necesita varias capas, pueden aparecer en un orden como:

**escritura original → romanización → IPA → explicación**

No todas las entradas necesitan todas las capas.

Cada una cumple una función distinta.

## Advertencias

Las advertencias no son excepciones molestas: son parte del contenido.

Pueden señalar:

- variación;
- equivalencias aproximadas;
- diferencias entre norma y uso;
- límites de una fuente;
- cambios históricos;
- decisiones analíticas.

## Entradas relacionadas

Los enlaces pueden indicar distintas relaciones:

- concepto previo;
- tema relacionado;
- comparación;
- mismo fenómeno en otro idioma;
- sistema de representación;
- contexto de variedad.

Un enlace no implica que dos fenómenos sean equivalentes.

## Fuentes y fundamento

Las fuentes mostradas al lector proceden de la evidencia utilizada para construir la entrada.

Cuando importe, también verás:

- variedad cubierta;
- localizador;
- alcance de la muestra;
- diferencia entre fuente normativa y descriptiva;
- desacuerdos relevantes.

La bibliografía no está ahí como decoración: debe corresponder al texto que estás leyendo.

## Una entrada no intenta decirlo todo

La modularidad del tomo significa que una entrada tiene límites deliberados.

Si para comprenderla necesitas otro concepto, debe enlazarlo en lugar de volver a explicarlo desde cero.

Así puedes profundizar cuando lo necesites sin cargar cada página con toda la teoría del libro.
