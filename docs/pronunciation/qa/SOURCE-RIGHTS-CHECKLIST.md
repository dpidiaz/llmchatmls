# MLS-SND — Checklist de derechos y reutilización

## Fuente

- [ ] DOI/URL correcto
- [ ] tipo de acceso registrado
- [ ] licencia explícita registrada si existe
- [ ] versión realmente consultada identificada

## Texto

- [ ] la entrada usa paráfrasis propia por defecto
- [ ] cualquier cita literal es breve y necesaria
- [ ] localizador conservado
- [ ] atribución preparada

## Figuras / tablas / mapas

- [ ] ¿se está copiando o recreando?
- [ ] licencia comprobada
- [ ] modificación permitida si aplica
- [ ] atribución requerida incluida
- [ ] alternativa propia evaluada

## Corpus

- [ ] licencia del corpus
- [ ] términos de redistribución
- [ ] audio separado de transcripción
- [ ] metadatos/personas tratados conforme a las condiciones del corpus
- [ ] ejemplo marcado CORPUS_EXAMPLE

## Audio futuro

- [ ] permiso/licencia
- [ ] atribución
- [ ] streaming vs redistribución definido
- [ ] formato final compatible

## Tipografía

- [ ] cobertura técnica verificada
- [ ] licencia verificada
- [ ] no se redistribuye archivo de fuente sin base explícita

## Estado

Si hay duda material:

**REUSE_CONSTRAINED** y bloquear publicación del elemento concreto, no toda la entrada si puede sustituirse por una descripción propia.
