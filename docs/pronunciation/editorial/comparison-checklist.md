# MLS-SND — Checklist de comparación entre idiomas

Uso interno para revisión editorial.

## Antes de escribir

- [ ] ¿La lengua objetivo está descrita primero por sí misma?
- [ ] ¿La variedad objetivo está declarada?
- [ ] ¿La comparación realmente ayuda?
- [ ] ¿La variedad de comparación también está delimitada?

## Sobre el tipo de relación

Seleccionar una sola etiqueta principal:

- [ ] IDENTIDAD DOCUMENTADA
- [ ] SEMEJANZA PARCIAL
- [ ] APROXIMACIÓN ARTICULATORIA
- [ ] SIN EQUIVALENTE DIRECTO ÚTIL

## Sobre las dimensiones

Comprobar si difieren:

- [ ] lugar de articulación
- [ ] modo
- [ ] fonación
- [ ] calidad vocálica
- [ ] duración
- [ ] distribución
- [ ] función fonológica
- [ ] prosodia
- [ ] variación dialectal/contextual

## Evidencia

- [ ] claim objetivo con fuente/localizador
- [ ] claim comparativo con fuente/localizador o referencia canónica ya validada
- [ ] advertencia si la semejanza es parcial
- [ ] no se deriva pronunciación desde grafía

## Red flags

Revisar expresiones como:

- “es igual que”
- “suena exactamente como”
- “equivale a la letra…”
- “simplemente pronuncia…”
- “es el mismo sonido que…”

No están prohibidas, pero exigen evidencia proporcional a su fuerza.
