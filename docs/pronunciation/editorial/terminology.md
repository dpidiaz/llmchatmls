# MLS-SND — Política de terminología

Estado: **norma editorial v0.2**.

Este archivo fija el uso interno de términos para prototipos. Cuando una definición sea una afirmación lingüística sustantiva dentro del tomo, deberá respaldarse con fuentes; aquí se fija ante todo **consistencia editorial**.

## 1. Principio

Términos cercanos no se tratarán como sinónimos por conveniencia.

Cuando una tradición lingüística emplee otra terminología, MLS-SND deberá:

1. indicar el término canónico usado por el tomo;
2. registrar la terminología de la fuente cuando sea relevante;
3. explicar diferencias analíticas reales;
4. evitar equivalencias terminológicas no demostradas.

## 2. Términos canónicos

### Fonética

Uso MLS: descripción/estudio de las propiedades y producción/percepción de los sonidos del habla.

**No equivale a:** fonología.

### Fonología

Uso MLS: organización lingüística de contrastes, unidades y patrones sonoros dentro de una lengua o variedad.

**No equivale a:** pronunciación física concreta.

### Pronunciación

Uso MLS: manera en que formas lingüísticas son realizadas en una lengua, variedad, registro o contexto delimitado.

Puede incluir decisiones segmentales y prosódicas.

### Prosodia

Uso MLS: organización temporal y melódica por encima o a través de segmentos, incluyendo cuando corresponda acento, duración, tono, ritmo, prominencia, fraseo e intonación.

No se asumirá que todas estas categorías funcionan de la misma manera en todas las lenguas.

### Ortografía

Uso MLS: convenciones de escritura establecidas para una lengua.

**Regla:** ortografía ≠ pronunciación.

### Escritura

Uso más amplio que ortografía: sistema gráfico y sus convenciones de representación.

### Romanización

Representación de una forma mediante letras latinas conforme a un sistema identificado.

**Regla:** romanización ≠ IPA salvo que una fuente específica defina una relación explícita y aun así deberán mantenerse las funciones separadas.

### Transliteración

Conversión sistemática entre sistemas de escritura orientada primariamente a representación gráfica, no necesariamente a pronunciación.

### Transcripción fonológica

Representación analítica de unidades o contrastes fonológicos; se usa normalmente entre / / cuando la convención sea aplicable.

### Transcripción fonética

Representación de realizaciones fonéticas; se usa entre [ ].

### Transcripción amplia

Representación fonética/fonológica con el nivel de detalle mínimo necesario para el objetivo descriptivo.

### Transcripción estrecha

Representación con detalle fonético adicional pertinente y documentado.

### Fonema

Unidad analítica fonológica que participa en contrastes dentro de un sistema descrito.

**Advertencia:** el inventario y análisis de fonemas puede variar entre fuentes.

### Alófono

Realización o conjunto de realizaciones relacionadas con una unidad fonológica según un análisis concreto.

**Advertencia:** no presentar como “alófono” una realización sin identificar el análisis que lo sustenta cuando exista controversia.

### Segmento

Unidad descriptiva tratada como elemento de una secuencia sonora sin comprometer necesariamente un análisis fonémico específico.

### Realización

Forma fonética concreta o rango de formas documentadas para una unidad o secuencia en un contexto.

### Sílaba

Unidad de organización fonológica cuya estructura debe describirse según la lengua. MLS no impondrá una única plantilla silábica universal más allá de conceptos introductorios generales.

### Fonotáctica

Restricciones y patrones de combinación/posición de segmentos dentro de estructuras como la sílaba o la palabra.

### Mora

Unidad de peso/temporización utilizada por determinados análisis y lenguas. No se tratará como sinónimo de sílaba.

### Acento

Término paraguas potencialmente ambiguo. En MLS deberá especificarse siempre una de estas lecturas cuando sea material:
- acento léxico;
- prominencia;
- acento gráfico/ortográfico;
- acento regional/social (“accent” en sentido sociolingüístico).

### Acento léxico

Propiedad de prominencia o patrón prosódico asociado a una palabra según el sistema de la lengua.

No implica necesariamente mayor intensidad.

### Prominencia

Saliencia relativa de una unidad dentro de una estructura prosódica. Su correlato acústico y función deberán describirse por lengua.

### Tono

Uso MLS: categoría o patrón de frecuencia fundamental con función lingüística en sistemas donde esté documentada.

No usar como sinónimo de intonación.

### Acento tonal

Etiqueta para sistemas analizados mediante prominencia léxica asociada a patrones tonales/pitch; deberá definirse específicamente en el perfil correspondiente.

No tratar japonés y mandarín como si compartieran el mismo tipo de sistema.

### Ritmo

Término descriptivo para organización temporal y patrones de prominencia. Se evitarán clasificaciones tipológicas simplistas sin evidencia.

### Intonación

Patrones melódicos/prosódicos asociados a unidades superiores a la palabra y a funciones discursivas, gramaticales o pragmáticas según la lengua.

### Duración

Dimensión temporal medible de sonidos o unidades.

### Cantidad

Uso fonológico de contrastes de duración/peso cuando una lengua y análisis lo justifiquen.

### Geminación

Contraste o realización de consonantes largas/dobles según el sistema descrito; no debe deducirse automáticamente de letras dobles.

### Variedad

Conjunto delimitado de usos lingüísticos relevante para la descripción: regional, social, estilístico u otro.

### Estándar

Etiqueta normativa o sociolingüística que solo se utilizará cuando una fuente o decisión editorial la defina. Nunca implica superioridad lingüística.

### Norma ortoépica

Conjunto codificado de recomendaciones o variantes aceptadas de pronunciación en una tradición normativa.

No equivale automáticamente al habla espontánea de todos los usuarios.

## 3. Términos que requieren especial vigilancia

- “sonido” — puede referirse informalmente a fono, segmento o categoría; evitar ambigüedad en pasajes técnicos;
- “letra” — nunca sustituye grafema o símbolo fonético cuando la distinción importe;
- “correcto” — reservar para reglas normativas explícitas; no usar contra variantes dialectales legítimas;
- “neutral” / “sin acento” — evitar como descripción no definida;
- “nativo” — no usar como criterio de calidad fonética;
- “pronunciación estándar” — siempre identificar la institución, tradición o variedad que la define.

## 4. Política de nombres

La primera aparición de un término técnico en un capítulo deberá:

1. usar el término canónico en español;
2. dar, si es útil, el equivalente internacional/inglés entre paréntesis;
3. enlazar a la entrada/glosario correspondiente.
