# MLS-SND — Checklist editorial de evidencia

Uso antes de marcar una entrada como EDITORIAL_REVIEW completada.

## Alcance

- [ ] El idioma está identificado.
- [ ] La variedad está identificada cuando es material.
- [ ] La fecha/población de la fuente aparece cuando cambia la interpretación.
- [ ] No se extrapola una muestra a toda una lengua.

## Fuente

- [ ] Cada fuente citada se utiliza realmente.
- [ ] La referencia corresponde a la edición/version consultada.
- [ ] Los claims materiales tienen localizadores.
- [ ] DOI/URL identifica la fuente correcta.
- [ ] Una fuente normativa está etiquetada como normativa.
- [ ] Un corpus está etiquetado como corpus/muestra.

## Redacción

- [ ] “Siempre”, “nunca”, “todos” y equivalentes tienen respaldo suficiente.
- [ ] No se usa “pronunciación correcta” para variación dialectal legítima.
- [ ] No se presenta “neutral/sin acento” como categoría no definida.
- [ ] Decisiones MLS usan lenguaje editorial explícito.
- [ ] Hipótesis/pendientes no aparecen como hechos.

## Comparaciones

- [ ] La lengua objetivo se explica antes de compararla.
- [ ] La comparación lleva una etiqueta MLS-SND válida.
- [ ] Compartir grafía no se usa como evidencia fonética.
- [ ] Compartir IPA amplio no se convierte automáticamente en identidad.

## Tiempo y cambio

- [ ] Un presente (“es”, “se pronuncia”) no depende únicamente de evidencia histórica cuando el cambio sea plausible/material.
- [ ] La fecha de datos de corpus antiguos está visible si afecta la conclusión.

## Ejemplos

- [ ] Cada ejemplo es SOURCE_EXAMPLE, CORPUS_EXAMPLE o EDITORIAL_EXAMPLE.
- [ ] Un ejemplo editorial no se usa como evidencia.

## Salida

Si cualquier punto material queda sin resolver:

**no promover a READY_FOR_COMPOSITION.**
