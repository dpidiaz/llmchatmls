# MLS-SND — Gate de validación R33

Estado: propuesta específica para este tomo.

## 1. Principio

R33 regula la **auditabilidad y validez evidencial** de las afirmaciones. No sustituye la redacción editorial ni determina el contenido lingüístico.

## 2. Entrada validada

Una entrada no podrá considerarse lingüística/evidencialmente validada hasta que:

1. su versión vigente esté identificada;
2. sus afirmaciones sustantivas estén delimitadas;
3. cada afirmación material tenga evidencia adecuada;
4. los localizadores hayan sido comprobados;
5. la fuente cubra realmente el idioma/variedad/contexto afirmado;
6. las transcripciones estén respaldadas o su adaptación esté documentada;
7. la terminología sea coherente con la política MLS-SND;
8. la variación relevante esté documentada;
9. las discrepancias entre fuentes estén resueltas o explícitamente presentadas;
10. la bibliografía APA 7 corresponda a las fuentes realmente utilizadas;
11. toda modificación sustantiva posterior fuerce nueva revisión de las afirmaciones afectadas.

## 3. Dos revisiones independientes

### Revisión editorial

Comprueba:

- claridad;
- estructura;
- estilo;
- navegabilidad;
- consistencia terminológica.

### Revisión lingüística/evidencial

Comprueba:

- exactitud;
- alcance;
- variedad;
- análisis;
- transcripción;
- fuentes;
- localizadores.

Una no sustituye a la otra.

## 4. Estados de trabajo propuestos

Estos estados son operativos de MLS-SND y no redefinen los estados canónicos de R33:

- `INVENTORY`
- `SOURCE_MAPPED`
- `RESEARCHED`
- `DRAFTED`
- `EVIDENCE_CHECKED`
- `LINGUISTIC_REVIEW`
- `EDITORIAL_REVIEW`
- `READY_FOR_COMPOSITION`

## 5. Prohibiciones

No debe marcarse una entrada como validada solo porque:

- tenga bibliografía;
- tenga IPA;
- cite una institución;
- haya pasado revisión de formato;
- se parezca a otra entrada;
- una fuente general mencione el idioma.

## 6. Unidad de evidencia

La unidad mínima preferida será la afirmación o pequeño cluster de afirmaciones estrechamente relacionadas, no la página completa.

## 7. Versionado

Cada gate debe corresponder a una versión concreta del texto. Si el contenido cambia de manera material, el resultado anterior no se hereda automáticamente.
