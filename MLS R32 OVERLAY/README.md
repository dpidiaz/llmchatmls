# MLS R32 FIFO + Publish First

Este overlay se aplica después de extraer el bundle canónico durante `predeploy`.

Su propósito es activar en producción la recuperación del backlog, FIFO estricto, Publish First y la sincronización de caché, sin retirar las protecciones de costo cero ni los proveedores aprobados que ya contiene la Revisión 32.

El bundle completo equivalente permanece como artefacto canónico validado.
