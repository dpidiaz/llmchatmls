#### En pocas palabras

El sufijo **-ção** forma muchos sustantivos a partir de verbos: **organizar → organização**, **decidir → decisão**.

Estos sustantivos suelen expresar acción, proceso o resultado.

#### Cómo funciona

La forma de la base puede cambiar: **produzir → produção**, **informar → informação**. No siempre basta añadir literalmente las letras **-ção**.

El género de estos sustantivos es normalmente femenino: **a decisão, a organização**.

#### Ejemplos

* **organizar → organização**
* **decidir → decisão**
* **produzir → produção**
* **informar → informação**

#### Observación importante

La relación morfológica puede implicar cambios ortográficos y fonológicos. Cada derivado debe aprenderse con su forma correcta.


La base puede experimentar cambios gráficos o fonológicos, de modo que no basta con añadir literalmente las letras **-ção**. Además, el sustantivo resultante puede designar acción, proceso, resultado o concepto relacionado: **organização** puede referirse tanto al acto de organizar como a una entidad organizada, según el contexto.
