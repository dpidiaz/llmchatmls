#### En pocas palabras

**Pedir para + infinitivo** puede introducir una solicitud dirigida a otra persona. En **Ela pediu para eu esperar**, la acción solicitada es **esperar**.

En portugués brasileño esta construcción es frecuente, especialmente en el habla, y puede incluir un sujeto explícito del infinitivo.

#### Cómo funciona

La estructura puede aparecer como **pedir para + infinitivo** cuando el responsable de la acción se entiende por contexto: **Pedi para esperar um pouco**. Para evitar ambigüedad puede expresarse el sujeto: **Pedi para ele esperar**, **Ela pediu para eu ligar mais tarde**.

Con pronombres sujetos, el portugués brasileño usa naturalmente formas como **para eu fazer**, porque **eu** es sujeto del infinitivo: **Pediu para eu enviar o arquivo**.

Existe también la construcción **pedir que + subjuntivo**: **Pediu que eu enviasse o arquivo**.

#### Ejemplos

* **Ela pediu para eu esperar.** — yo debo realizar la acción solicitada.
* **Pedi para ele fechar a porta.** — el sujeto del infinitivo es **ele**.
* **O gerente pediu para chegar mais cedo.** — el responsable puede recuperarse del contexto.
* **Nós pedimos para vocês confirmarem o horário.** — el infinitivo personal puede marcar plural.

#### Observación importante

No debe corregirse **para eu fazer** a *para mim fazer* en la norma estándar cuando **eu** funciona como sujeto del infinitivo. **Mim** puede aparecer como complemento, no como sujeto de una forma verbal en ese patrón normativo.

La distribución entre **pedir para + infinitivo** y **pedir que + subjuntivo** varía según registro, estructura y preferencias de uso.
